# Results

No result files have been imported yet.

Use `results/<simulator>/<run-id>/` for each run. A run record should include:

- Goal, date, status, and test conditions.
- Repository commit used to run, upstream simulator/engine versions, and exact commands.
- GPU, driver, OS, dependency versions, configuration, and seeds when applicable.
- Measured results with units, methodology, and limitations. Include failures and incomplete tests.
- Small metrics or plots committed here, plus links to large output artifacts.
- Large artifact filenames, byte sizes, SHA-256 checksums, and verified durable locations.

Imported historical results must identify their original source and any unrecovered settings or artifacts. Do not present a remembered metric as a newly reproduced result.
