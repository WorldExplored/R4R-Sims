## Complete Free Linux camera path: bounded investigation

Checked October 8 local / October 9 UTC; exact retrieved bytes/hashes are in [the source manifest](../../results/rflysim/local-20261009T020939Z/source-manifest.json).

- [CopterSim manual](https://rflysim.com/doc/en/3.Soft/coptersim.html), Supported Platforms, documents Windows/Linux dynamics. It does not supply a Linux Free visual binary.
- [Install steps](https://rflysim.com/doc/en/1.Start/install.html) specify a Windows mounted ISO and `.exe` fast installer. [Docker architecture](https://rflysim.com/doc/en/3.Soft/docker.html#integration-with-rflysim-simulation) places **CopterSim/RflySim3D on Windows Native**, algorithms in WSL2/Docker. This describes algorithm portability, not a complete Linux renderer release.
- [Resource index](https://rflysim.com/doc/en/4.DevRef/3d-res.html#i-3d-models) says Free ships UE4 RflySim3D, excludes UE5. [Sensor licensing](https://rflysim.com/doc/en/4.DevRef/vis-cfg.html#version-restriction-overview) documents RGB Type1, ≤3 sensors/vehicle1, but warns that actual binary/license wins over inconsistent documentation. Neither page establishes a downloadable Linux Free binary.
- [Pinned camera implementation](https://github.com/RflySim/RflySimVision/blob/49d60c0907e67cef9c768ac28d89f9c3232f07a7/sensor_pkg/VisionCaptureApi.py#L1380) opens an **already existing** `/dev/shm/RflySim3DImg_<SeqID>` on Linux. It does not create the scene renderer. Linux consumers/ROS/relay are separate components.
- Official GitHub release listings for CopterSim, RflySimVision, doc and Docs returned no releases. RflyExpCode has two tags with no assets and one 19,964,088-byte `RflyExpCode1.zip` example asset. [Exact listings](../../results/rflysim/local-20261009T020939Z/release-assets.json) contain URLs/bytes. None inspected provides the complete licensed Free Linux renderer. The author account's repository inventory was inspected; no separately named RflySim3D release repository was listed.
