Neither stock scene represents the lab's reconstructed suburban environment or a real held-out trajectory. [Release assets](https://github.com/iamaisim/ProjectAirSim/releases/tag/v1.0.1).

Project AirSim source is MIT; packaged UE and environment contents may carry third-party terms. No redistribution of the binary is planned. The native Runtime lacks rendered cameras, LiDAR/radar and general mesh collisions according to [upstream Runtime notes](https://github.com/iamaisim/ProjectAirSim/blob/v1.0.1/samples/projectairsim_runtime/README.md). It cannot replace the camera renderer for this audit.
